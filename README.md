# FPGA Projects

A growing collection of my FPGA projects using **Verilog**, **AMD Vivado**, **Vitis Model Composer**, and the **Digilent Basys 3**.

## Projects

| # | Project | Description |
|---|---|---|
| 01 | [Model Composer AND Gate](01-model-composer-and-gate/) | Two-input registered AND gate designed in Vitis Model Composer, exported to Verilog, synthesized in Vivado, and verified on a Basys 3. |
| 02 | [Model Composer 4-Bit Counter](02-model-composer-4bit-counter/) | Four-bit counter with enable/reset, Model Composer simulation and Vivado implementation, plus verified standalone boot from Basys 3 SPI flash. |

This repository is intended to document my progression from small FPGA fundamentals into larger RTL, digital-design, and embedded-FPGA projects.
